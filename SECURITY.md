# Security policy

Please report vulnerabilities privately using
[GitHub's vulnerability reporting form](https://github.com/prompthunt/committed/security/advisories/new).
Include the affected version, reproduction steps, and expected impact. Do not post
credentials, personal GitHub data, or an unpatched exploit in a public issue.

Security fixes target the latest official release. Official downloads and Sparkle
updates are published only through `prompthunt/commit-standings-releases`.
Never install an update that fails its signature checks.

GitHub OAuth client IDs and the Sparkle verification key in the source are public
identifiers. Access tokens, private signing keys, certificates with private keys,
and notarization credentials must stay outside the repository.
